### 1. 장식을 셰이더 수식에서 텍스처 읽기로 전환
- 대상: 통·몸통·구 장식(갑옷줄·리벳·테두리·띠·버클·멜빵·가슴 능선), 사슬 무늬, 정강이·아래팔 능선.
- 방식
  - 장식표 줄(`DEC`)을 `atBake()`가 그림판(`AT`, 텍스처 유닛 7)에 미리 굽고, 셰이더는 읽기만 한다.
  - 그림판은 가로 8칸(칸 = 256²). 통·구는 한 칸, 몸통은 2×2칸(앞·뒤).
  - 윗절반 = 바탕색(알파 곱한 RGB, A), 아랫절반 = (R 먹선, G 가슴 능선).
  - `decUp()`은 줄 내용이 같으면 다시 굽거나 올리지 않는다. 줄 내용이 같은 타일은 `AT_TILES`에서 다시 쓴다.
  - 사슬 무늬는 `LT`의 B칸, 정강이·아래팔 능선은 `LT`의 A칸에 구웠다(능선 세로축 = 반지름 0~14).
- 꼬리표: `HLA w = 10 + 종류 + 3·칸 번호`(종류 0 통, 1 몸통, 2 구). 통의 `vh.z`는 (축 위치 + 1) ÷ (길이 + 2), 몸통은 `vh = (좌우/Yh, 높이 0~1, 앞뒤)`.
- 확인: 5개 모델 × 3방향 화면 비교에서 달라진 픽셀 약 200~400개(전체의 0.04% 안팎).
- 알아 둘 점
  - 처음 굽는 데 약 200ms(소프트웨어 렌더 환경). 부품 치수가 바뀌면 그 줄만 다시 굽는다.
  - 사슬 두건 뒤쪽 이음선(방위각 ±π)에 가는 선이 보일 수 있다.
  - 능선 반지름 범위를 6으로 잡았다가 장갑 쪽에 검은 쐐기가 생겨 14로 늘렸다(반지름이 범위를 넘으면 REPEAT로 감겨 엉뚱한 값을 읽는다).

### 2. 금나라 투구 드림 올림을 2D와 비슷하게
- 2D(`knight.js` `jinDraw`)에 있고 3D에 없던 것을 `helm()`의 금나라 투구·투구2 드림 올림 분기에 추가했다.
  - 귀 옆 속드림 자락: 금나라 투구는 양옆 두 자락, 투구2는 옆과 뒤 네 자락. 아래로 갈수록 벌어지고 찰갑 무늬.
  - 밑단 천: 접은 챙 아래 가장자리와 자락 밑단에 천 색 띠.
  - 턱 끈과 매듭: 자락 밑에서 붉은 끈이 나와 턱 앞에서 묶이고 끝자락 두 가닥이 늘어진다.
- 2D는 턱 밑에서 묶지만 3D는 몸통 윗면이 턱 바로 밑이라 끈이 파묻혀서 턱 앞쪽(`HL([6.9,0,-9.4])`)에서 묶는다.
- 끈의 `tube`·`ellip`은 `'mesh'`·`'bone'` 두 모드에서 똑같이 호출한다(뼈 등록 순서 규칙).

- 보완: 드림 올림에서는 귀를 그리지 않는다(`face(true,true)`). 말린 드림(접은 챙)에도 찰갑 무늬를 입혔다(`TAG=1`, `HLOC=null`).

- 보완 2: 드림 올림에서 뒤통수 맨머리에 머리카락을 넣었다(`hairCap()`, 모델의 머리 설정을 따른다). 말린 드림의 위쪽 면이 판판해 보여서 위쪽 면에도 찰갑 무늬를 입혔다. 새 TAG 4 = 찰갑 + 위를 향한 면도 무늬(같은 `LT` 그림을 위에서 내려다본 투영으로 읽는다. 수식으로 그리지 않고 텍스처를 읽는다).

- 되돌림과 수정: 드림 올림 전체 재작성(층층 돔·좁은 자락·늘어진 끈)은 마음에 들지 않아 되돌렸다. 기존 금나라 투구 모양에서 **말린 드림(접은 챙)만** 참고 그림대로 고쳤다. 두 단으로 포개 말린 띠(아래 단은 아래로 벌어지고, 위 단은 한 칸 물러나 계단을 이룸), 윗면·옆면 모두 찰갑 무늬. 사발·속드림 자락·턱 끈은 그대로다.

- 귀 자리 구멍 막기: 드림 올림에서 속드림 자락이 머리카락(반지름 10.3/9.3)보다 안쪽이라 머리카락이 뚫고 나와 구멍처럼 보였다. 자락을 머리카락 바깥(`gi=-.5`)에 두어 해결했고, 머리카락의 귀 자리 계단도 없앴다(`hairCap(true)`).
- 드림 단 조정 옵션: 3D 월드2 표시줄(외곽선·경계선·갑옷줄 줄)에 '드림 단' 슬라이더(1~4단, 기본 2)를 `mkUI()`가 끼워 넣는다. 값은 `opt.drimStep`(기존 옵션 저장소 `model-ed-opt`에 함께 저장), 메쉬 캐시 키에 포함된다. 1단은 아래로 벌어지는 매끈한 띠, 단이 많을수록 한 칸씩 물러나는 계단이 늘어난다. editor.js·shell_head.html은 건드리지 않았다. 모델 설정이 아니라 화면 옵션이라 모델별로 저장되지는 않는다.

- 드림 단 보완: 단이 늘수록 전체 키가 커지도록 바꿨다(높이 = 5 + (단-1)×2.8, 단마다 약 1.15씩 물러남). 3~4단은 청나라 강시 모자처럼 층층이 솟은 평평한 꼭대기 모양이 되고, 꼭대기 깃털도 그 위로 올라간다. 1단은 예전의 매끈한 띠.

- 드림 모양 옵션(강시모·빵모): 표시줄의 '드림' 선택(`opt.drimShape`: 0 기본, 1 강시모, 2 빵모)을 추가했다. 강시 모자는 챙이 위로 갈수록 벌어지는 모양이라, 강시모는 단마다 위로 벌어지는 층층 사다리꼴(단 슬라이더로 단 수·높이 조절)이고, 빵모는 사발 대신 위가 넓고 둥글게 부푼 모자가 머리를 덮는다(단 슬라이더 비활성). 금나라 투구(말린 드림)에만 적용된다. 위 '드림 단 보완'의 아래로 벌어지는 층 모양은 '기본'에 해당한다.

- 빵모 재작성(참고 사진: 세일러캡): 속이 꽉 찬 모양이 아니라 **속이 빈 챙 벽 + 그 안에 낮게 앉은 둥근 머리 윗부분**으로 만든다. 챙 벽은 바깥쪽이 위로 살짝 벌어지고 말린 가장자리를 돌아 안쪽으로 내려오는 위아래 열린 통(찰갑 무늬). 머리 윗부분은 챙 벽보다 낮고 평평하게 부푼 반구(무늬 없음). '드림 단' 슬라이더로 챙 벽 높이를 키운다(높이 = 5 + (단-1)×2.8).

- 빵모에서는 귀를 가리는 속드림 자락과 턱 끈을 없애고 귀를 보이게 했다(`BM`일 때 `face(true,false)`, 머리카락은 귀 자리 계단이 있는 기본형 `hairCap(false)`). 금나라 투구·강시모는 그대로 귀를 가린다.

- 강시모에 빵모 모델 적용: 강시모도 빵모와 같은 구조(속이 빈 챙 벽 + 안쪽에 낮게 앉은 머리 윗부분, 귀 보임, 속드림 자락·끈 없음)로 바꿨다(`BM = 드림 올림 && 금나라 투구 && 모양 > 0`). 차이는 챙 벽의 단면뿐이다. 빵모는 매끈하게 벌어지는 벽, 강시모는 단마다 .8 벌어지고 .25 물러나는 층층 벽. 두 모양 모두 '드림 단'으로 챙 벽 높이를 조절한다.

- 강시모 전용 옵션 2개: 표시줄에서 '드림'을 강시모로 고르면 '강시모 단차' 슬라이더(0~2, `opt.drimGap`, 기본 .55)와 쌓임 방향 선택(`opt.drimDir`: 0 위로 벌어짐, 1 위로 좁아짐)이 나타난다. 단차 = 층마다 옮겨 앉는 반지름이고, 방향이 '좁아짐'이면 탑처럼 위로 좁아진다(층 반지름 최소 8.5). 좁아질 때는 안쪽 머리 윗부분(`kc`)도 벽에 맞춰 줄인다. 방향은 2단 이상일 때만 눈에 띈다. 빵모에는 영향이 없다.

- 강시모 옵션 추가: 쌓임 방향에 '아래로 벌어짐'(`opt.drimDir`=2)을 넣었다. 각 층 벽이 아래가 넓은 종 모양이고, 층은 위로 좁아진다. '층 겹침' 슬라이더(0~3, `opt.drimOv`)는 윗층이 아랫층 위로 포개지는 높이이며 2단 이상에서 보인다(전체 키는 그대로, 층 하나의 키가 겹침만큼 커진다). '붙는 거리'를 층이 포개지는 길이로 해석해 만들었다.

- 강시모 보완: ① '층 겹침'을 키우면 그림만 포개지는 게 아니라 모델 전체 키도 줄어든다(키 = 5 + (단-1)×2.8 − (단-1)×겹침, 층 높이는 그대로, 겹침은 층 높이의 90%까지). ② '아래로 벌어짐'은 첫 층만 위에 두고 2단부터 머리 아래쪽으로 층을 포갠다(층 높이 2.8, 겹침만큼 윗층과 포개짐). 아래 층일수록 단차만큼 더 벌어지고 각 층은 아래가 넓다. 층이 얼굴 위쪽을 가릴 수 있다.

- 겹침 규칙 수정: 1단은 포개는 대상에서 제외한다. 2단은 1단에 붙기만 하고, 포개짐은 3단부터(2단 위에 포개는 것부터) 적용한다. 키 = 5 + (단-1)×2.8 − (단-2)×겹침(2단 이하면 겹침 없음). 아래로 벌어짐도 같은 규칙이다.

- 투구 기준 정리(강시모·빵모): 투구는 드림 내림 때 모델의 **원래 사발(10.8×10×10.5)을 그대로** 쓰고, 드림만 말아 올린다. 그동안 사발을 빼고 넓은 머리 윗부분으로 바꿨던 것을 되돌렸다.
  - 강시모 1단: 사발 아랫부분(밑동~4.5 위)에 사발 곡면을 따라 .7 두께로 겹쳐 감긴 띠.
  - 강시모 2단부터: 두께 .6의 닫힌 고리 층(높이 2.8)을 방향 옵션대로 포갠다. 위로 벌어짐/좁아짐은 1단 위로 쌓고(단차만큼 반지름이 늘거나 줄어듦), 아래로 벌어짐은 사발 밑동에서 머리 아래쪽으로 내려간다. 2단은 1단에 붙기만 하고 겹침은 3단부터.
  - 빵모: 사발 밑동에서 위로 벌어지는 속 빈 챙 벽. 안쪽으로 원래 사발이 보인다.
  - 밑단 천은 사발 밑동으로, 꼭대기 깃털은 원래 사발 꼭대기로 옮겼다.

- 카메라 위아래 회전 제한 풀기: editor.js는 시점 끌기에서 `VIEW.sq`를 .2~1로 묶는다(동결 파일이라 그대로 둠). `orbitUI()`가 3D 월드2에서 시점을 끌 때만 editor 처리 뒤에 이어 받아 -.95~1로 넓힌다(음수 = 아래에서 올려다보기). 다른 월드로 나가면 `show(false)`에서 .2 아래 값을 .2로 되돌린다. 바닥 격자는 editor가 2D로 그리므로 아래에서 볼 때도 모델을 가리지 않는다.

- 층 겹침 범위 0~6, 기준 3(기본값): 아래로 벌어짐에서는 겹침이 **1단의 위쪽 라인**에서 시작한다. 3 = 모든 층이 그 라인에 겹쳐 앉음(변화 없음), 0 = 층마다 한 층 높이(2.8)씩 아래로(최대 아래로 겹침), 6 = 층마다 위로(최대 위로 겹침). 위로 벌어짐·좁아짐에서는 3 이하가 겹침 없음, 3보다 크면 그만큼 겹친다(층 높이의 90%까지).

- 화면·투구 정리(world3d2.js에서만, 동결 파일은 그대로):
  - `mkUI()`/`patchPanel()`: 모델 탭이 다시 그려질 때마다(MutationObserver) 덧붙여 고친다. 1안·2안·3안 묶음 제거(2D에서도), 투구 형태에 '조관' 버튼 추가, 3D 월드2일 때 모델 탭 맨 위에 '3D 표시'(명암·외곽선·경계선·갑옷줄 — 무대 표시줄의 원래 조작부를 대신 움직이는 대리 조작부), 금나라 투구를 고르면 '드림 상태' 아래에 드림 조정(단·단차·층 겹침). 무대 위 표시줄에는 인원만 남는다.
  - 드림 모양은 강시모 하나(기본·빵모 제거), 쌓임 방향은 아래로 벌어짐 하나(위로 벌어짐·좁아짐 제거). `dshape()`=1, `ddir()`=2로 고정.
  - 새 투구 '조관'(`hkit.form='joguan'`): 빵모 1단 모양의 검은 관. 원래 사발 + 사발 밑동에서 위로 벌어지는 속 빈 챙 벽, 찰갑 무늬 없음, 귀 보임. 2D는 이 형태를 몰라 면갑 투구로 그린다.

- 조관 꼭대기 장식·색: 투구 칸의 '꼭대기 장식'(볏·깃털·뿔·없음)을 사발 꼭대기에 단다(`deco`). 색은 투구 '몸체' 색(정하지 않으면 검정).
- 아래 재생줄(`#tl`: 재생·키·+키)은 동작 탭에서만 보인다(`patchPanel`이 탭에 맞춰 숨김).
- 월드 버튼: 예전 '3D 월드' 버튼을 없애고 '3D 월드2' 버튼 이름을 '3D 월드'로 바꿨다. 저장된 월드가 예전 3D 월드면 새 3D 월드로 옮긴다. world3d.js 코드는 동결이라 그대로 남아 있지만 화면에서 쓸 길은 없다. editor.js가 그리는 안내 문구('3D 월드2는 판금 기사와…')는 동결 파일이라 그대로다.

### 3. 폴리곤 부위별 집계
- `pmk(이름)`: 직전 표시 뒤에 쌓은 삼각형 수를 부위로 적는다. `pmx(이름,시작)`: 안쪽에서 따로 센 몫(얼굴·머리카락)을 적는다.

### 시험 방법 메모
- Playwright chromium, `--use-gl=angle --use-angle=swiftshader`. 3D 월드2 전환은 `#worldsw button[data-world="3d2"]`.
- 시점은 `VIEW.yaw`(옆 0, 비스듬 .6, 정면 1.5708), 피치는 `VIEW.sq`를 직접 바꾼다.
- 금나라 투구 설정: `Object.assign({},KPRESETS[0].m,{armor:'jin',helm:'kit',hkit:{form:'jin',visor:'up',crest:'plume',colors:{}}})`
- 2D 월드는 소프트웨어 렌더에서 매우 느려 화면 한 장에 1분 넘게 걸린다. 한 번 접속에 한 장만 찍는다.
