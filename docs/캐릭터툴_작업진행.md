### 금나라 투구
- **드림 내림**: 기존 그대로(눈구멍 뚫린 드림, 찰갑 무늬).
- **드림 올림 = 강시모 하나**: 원래 사발(10.8×10×10.5)은 그대로 두고 드림만 말아 올린다.
  - 1단: 사발 아랫부분(밑동~4.5 위)에 사발 곡면을 따라 .7 두께로 겹쳐 감긴 띠.
  - 2단부터: 두께 .6의 닫힌 고리 층(높이 2.8)을 **아래로 벌어짐**으로 포갠다. 아래 층일수록 단차만큼 더 벌어지고 각 층은 아래가 넓다.
  - 층 겹침(0~6, 기준 3): 겹침은 1단의 위쪽 라인에서 시작. 3 = 모든 층이 그 라인에 겹쳐 앉음, 0 = 층마다 한 층 높이씩 아래로, 6 = 층마다 위로.
  - 귀가 보이고, 속드림 자락·턱 끈은 없다. 뒤통수에는 모델 머리 설정대로 머리카락. 밑단 천은 사발 밑동, 꼭대기 장식은 원래 사발 꼭대기.
- **금나라 투구2**는 드림 올림이 예전 방식(옆·뒷자락, 턱 끈)이다. 강시모 적용 대상이 아니다.

### 새 투구 '조관'
- `hkit.form='joguan'`. 원래 사발 + 사발 밑동에서 위로 벌어지는 속 빈 챙 벽(높이 5). 찰갑 무늬 없음, 귀 보임.
- 색은 투구 '몸체' 색(정하지 않으면 검정). 꼭대기 장식(볏·깃털·뿔·없음)은 투구 칸의 '꼭대기 장식'을 따른다.

### 새 투구 '클로즈헬름'
- `hkit.form='close'`. 참고: 16세기 클로즈헬름(책 그림). 볏 달린 사발 + 옆 회전축 하나에 함께 걸린 뾰족한 면갑(위, 눈 틈)과 턱가리개(아래, 앞 능선) + 목 겹판 3단(리벳).
- 사발의 앞(면갑·턱가리개가 덮는 자리)은 비워 두었다. **면갑 올림**이면 면갑만 회전축을 중심으로 젖혀(1 rad) 얼굴이 보인다.
- 면갑 상태(내리기·올리기)는 투구 형태 아래에 `#w3cvis`로 덧붙인다(동결 파일의 `canVisor`에 'close'가 없어서).
- 꼭대기 장식: 볏(높은 볏)·깃털(낮은 볏+깃털)·뿔(낮은 볏+뿔)·없음(낮은 볏). 색은 투구 '몸체' 색.

- **조립 몸체의 '클로즈' 얼굴**: 투구 형태 '조립 몸체'의 얼굴 가리개에 '클로즈'(`hkit.face='close'`)를 덧붙였다. 조립 몸체의 정수리·높이·폭·챙·목가리개·장식·띠·리벳은 그대로 쓰고, 클로즈헬름의 면갑·턱가리개·눈 틈·회전축 리벳을 그 몸체에 건다(공용 `closeVis()`). 몸체의 앞쪽은 비우고, 면갑 상태(`#w3cvis`)는 얼굴 가리개 아래에 나온다. 눈구멍·숨구멍 항목은 숨긴다.

- **조립 몸체 얼굴 가리개에 다른 투구의 앞부분**(사용자 선택: '얼굴 가리개 선택지' 방식). 정수리·챙·목가리개·장식·띠·리벳은 조립 몸체 것을 그대로 쓴다.
  - '뾰족 투구'(`peak`)·'면갑 투구'(`closed`): 그 투구의 면갑과 같은 눈 틈·숨구멍·능선·축(투구 그림판). 면갑 상태 내리기·올리기(올리면 앞을 비우고 젖힌 면갑판, 얼굴 보임). 눈구멍·숨구멍 항목은 그대로 쓴다.
  - '챙 투구'(`kettle`): 트인 얼굴 + 넓게 처진 챙.
  - '조관'(`joguan`): 트인 얼굴 + 밑동에서 위로 벌어지는 챙 벽(몸체 색).

- **조립 몸체 '투구드림'**: 찰갑드림 바로 위. 목드림과 따로 고른다: 없음·짧은·긴·퍼진·사슬(`hkit.hdrim`) + '투구드림 길이'(`hlen`)·'투구드림 퍼짐'(`hspr`). 투구 밑단에서 늘어뜨리고, 얼굴이 트였으면 앞을 비운다. 닫힌 얼굴이면 목드림 바깥에 겹친다(밑단 -5, 반지름 +.7).
- **조립 몸체 칸 순서·이름**(화면만): (투구 형태) → 머리에 쓰는 것 → 정수리 → 챙 → 투구(원래 '얼굴 가리개') → [면갑 상태·눈구멍·숨구멍] → 투구가리개 → 찰갑드림 → 투구드림 → 목드림 → 꼭대기 장식. 챙은 투구 위로 옮겼고, 투구 목록에서 코가리개·볼가리개를 뺐다. '머리에 쓰는 것'(투구·사슬 두건·천 두건·맨머리)은 조립 몸체일 때만 정수리 바로 위로 옮긴다(다른 투구 형태·두건·맨머리일 때는 원래 자리).
- **투구(얼굴 가리개) 이름·순서**(화면만, 값은 그대로): 경투구(`open`, 트인 얼굴) · 챙 투구(`kettle`) · 조관(`joguan`) · 통투구(`mask`, 평면 가면) · 바이저1(`closed`, 면갑 투구) · 바이저2(`peak`, 뾰족 투구) · 바이저3(`close`, 클로즈). '면갑'(`visor`) 단추는 뺐다(예전 모델은 그대로 그린다).
- **바이저 튀어나옴**(`hkit.vpro`, 0.3~2, 기본 1): 바이저1·2·3을 고르면 면갑 상태 아래에 나온다. 바이저1·2는 면갑 앞 돌출(`visor()` 마디의 앞 거리)을, 바이저3은 면갑·턱가리개의 뾰족한 정도(`closeVis` pk)를 곱한다. 형태 칸의 클로즈헬름 자체는 1 고정.
- **투구드림 여밈·문양**: 투구드림을 고르면 '여밈 · 턱 감싸기'(`hkit.hdwrap`, 켜고 끄기)와 '드림 문양'(`hkit.hdpat`: 없음·징·찰갑·비늘·쇠사슬)이 나온다(참고: 사용자가 보낸 조선 장수 그림).
  - 여밈: 트인 얼굴일 때 입 아래(-5 ~ -7.5)부터 앞이 닫히고 앞쪽을 턱 쪽으로 당겨 감싼다. 닫힌 얼굴이면 효과 없음.
  - 징: '띠·테두리' 색 납작한 못머리(드림과 같은 부품 번호라 경계선이 없다). 찰갑: TAG 1. 비늘(어린갑의 물고기 비늘): 아래가 반원인 비늘판 18×8개를 줄마다 반 칸씩 엇갈리고, 위 줄을 조금 더 바깥에 두어 아래 줄 윗부분을 덮는다(비늘마다 경계선). 예전에는 비늘 폭 계산이 틀려 가는 빗금처럼 보였다. 쇠사슬: 사슬 무늬(HLA w 2). 드림 종류 '사슬'에 문양 '없음'이면 예전처럼 사슬 무늬.
- 바이저3 눈 틈·숨구멍 통은 면갑·턱가리개와 같은 부품 번호로 그려 구분선(경계선)이 생기지 않는다.
- **바이저3 눈구멍·숨구멍**: 조립 몸체 바이저3(`close`)도 '눈구멍'(한 줄·두 줄·T자·두 눈·없음)·'숨구멍'(구멍·세로 틈·한쪽 틈·없음)을 고른다. 그림판이 아니라 먹선 통으로 만든다: 눈 틈은 면갑 위(면갑과 함께 젖혀짐), 숨구멍은 턱가리개 양 볼. 기본은 한 줄·없음. 형태 칸의 클로즈헬름은 한 줄·없음 고정.
- **투구가리개**(`#w3pgd`): 코가리개(`hkit.nasal`)·볼가리개(`hkit.cheek`)를 켜고 끄는 단추. 둘 다 켤 수 있고 투구(얼굴 가리개)와 상관없이 붙는다. 값이 없으면 예전 `face='nasal'|'cheek'`을 따른다(이때 투구는 트인 얼굴로 본다).
  - 얼굴가리개(`hkit.fmask`): 사람 얼굴 모양 철가면(참고: 사용자가 보낸 사람 얼굴 철가면 투구 사진). 얼굴 곡면에서 .85 띄운 격자에 코 능선·입술·턱을 돋우고, 눈구멍을 뚫어 안의 눈이 보인다. 입 선(먹선 통), 양옆에 '띠·테두리' 색 장식 귀. 몸체 색.
  - 코가리개는 토막 3개 대신 통 하나라 토막 사이 구분선이 없다.
  - 볼가리개는 앞·뒷면을 얼굴 곡면을 따르는 격자로 만들어, 판 가운데로 얼굴이 뚫고 나오던 구멍을 메웠다.
- **면갑 상태 위치**: 조립 몸체에서 원래 '면갑 상태'(면갑·평면 가면 얼굴일 때, 형태 칸 바로 아래에 나오던 것)를 얼굴 가리개 바로 아래로 옮긴다.
- **조립 몸체 '찰갑드림' 항목**(예전 이름 투구드림. 얼굴 가리개에서 분리, 목드림 앞 `#w3pdr`): 없음·찰갑드림(`hkit.drim='jin'`, 예전 이름 금나라 드림)·찰갑드림2(`'jin2'`), 드림 상태(`hkit.dvis`). 얼굴 가리개와 함께 고를 수 있다(드림이 있으면 몸체 앞은 트인다).
  - 내리면 눈구멍 뚫린 찰갑 드림(공용 `jinDrim()`) + 드림 틈 눈 모양(`fEye`)·안대(`patch`).
  - 금나라 드림 올림은 금나라 투구와 같은 강시모(1단 띠 + 2단부터 아래로 벌어지며 포갠 층, 밑단 천). 드림 조정(단·단차·층 겹침)이 나오며 값은 금나라 투구와 같은 화면 옵션(`opt.drimStep/drimGap/drimOv`)을 쓴다.
  - 금나라 드림2 올림은 옆·뒷자락·밑단 천·붉은 끈.
  - 예전에 얼굴 가리개로 고른 금나라(`face='jin'|'jin2'`)는 드림으로 읽고 얼굴은 트인 얼굴로 본다.
- **조립 몸체 '목드림'**: 원래 '목가리개'(서양 기사 목가리개: 짧은·긴·퍼진·사슬, `hkit.neck`)를 '목드림'이라는 이름으로 늘 보이게 둔다(얼굴 가리개와 무관). 목을 한 바퀴 감싸는 고리(-7부터). '목드림 길이'(`nlen`)·'목드림 퍼짐'(`nspr`)(`#w3pnk`). 메쉬는 공용 `guard()`가 투구드림과 함께 만든다.
- 목가리개를 나눈 것은 사용자 지시. 지금은 투구드림(빈 칸)·찰갑드림·목드림 순서.

### 시작 월드
- 처음 열면 3D 월드로 시작한다(world3d2.js 끝에서 `setWorld('3d2')`). 월드 선택은 원래 저장되지 않는다.

### 머리에 쓰는 것(작동 방식 변경)
- 단추 3개를 켜고 끄는 방식: 투구(`hwear` 'helm'/'none') · 사슬 두건 · 천 두건(`m.hood` 'coif'/'hood'/''). 모두 끄면 맨머리. 두건은 둘 중 하나, 투구와는 함께 쓸 수 있다. 두건을 켜고 꺼도 투구 상태는 그대로.
- 두건 + 투구: 두건(얼굴 구멍·어깨 자락)을 먼저 그리고 그 위에 투구를 덧쓴다. 얼굴은 한 번만 그린다(`helm()`의 `FONCE`), 두건 속 머리카락은 그리지 않는다, 천 두건 꼬리는 뺀다.
- 예전 값(`hwear`='coif'|'hood')은 화면을 열 때 `hood`로 옮기고 `hwear='none'`으로 바꾼다. 2D 월드는 `m.hood`를 모른다(2D에서 두건만 쓴 모델은 맨머리로 보인다).

### 강철 치마 '톤렛'
- 모델 값 `m.tonlet`(참/거짓). 3D 월드에서만, 판금 갑옷일 때 갑옷 칸 '겉옷 (서코트)' 아래에 '강철 치마 (톤렛)' 입음·없음(`#w3ton`, `mbool`).
- 허리(H0+5)에서 무릎 위까지 종 모양으로 벌어지는 가로 겹판 6장. 위 판의 밑단이 아래 판 윗단을 덮는다. 밑단은 '허리띠'(trim) 색 테.

## 2. 결정한 사항과 근거
| 결정 | 근거 |
|---|---|
| 동결 파일(editor.js·helmimport.js·shell_head.html 등)은 고치지 않고 world3d2.js에서 DOM을 덧붙여 화면을 바꾼다 | `CLAUDE.md` 작업 원칙(3D 월드2에만 적용). 화면 정리 요청 때 사용자가 "world3d2.js에서만 처리"를 골랐다 |
| 셰이더 수식으로 그리던 장식은 텍스처에 구워 읽는다 | 사용자 지시("셰이더로 그려 넣는 것은 텍스처에 그려서 넣기"). 수식 대신 텍스처 조회만 남겨 셰이더를 단순하게 함 |
| 드림 올림은 드림 내림 모델의 원래 사발을 기준으로, 드림만 말아 올린다 | 사용자 지시. 한때 사발을 빼고 넓힌 머리 윗부분을 썼으나 원래 투구 크기와 달라 되돌림 |
| 드림 모양은 강시모 하나, 방향은 아래로 벌어짐 하나 | 사용자 지시(기본·빵모·위로 벌어짐·위로 좁아짐 제거) |
| 1단은 포개지 않고 2단부터 포갠다. 겹침은 1단 위쪽 라인에서 시작, 기준 3 | 사용자 지시. 겹침이 그림만이 아니라 모델 높이에도 반영되게 함 |
| 빵모는 없애고 빵모 1단 모양을 새 투구 '조관'으로 | 사용자 선택("빵모 제거") |
| 강시모·조관은 귀가 보이고 속드림 자락이 없다 | 빵모 때 사용자 지시("귀 가리는 드림 제거, 귀 보이게")를 강시모에도 적용하라는 지시("빵모 모델을 강시모에 적용") |
| 드림 옵션·3D 표시는 모델 설정이 아니라 화면 옵션(`opt`, `model-ed-opt`)에 저장 | 모델 설정을 바꾸려면 동결 파일을 고쳐야 함 |
| 세션마다 자기 아티팩트에만 배포 | 사용자 지시("다른 세션의 아티팩트 수정 금지"). 같은 파일 경로로 올리면 예전 링크가 갱신되는 사고가 있어 사본 경로를 따로 둔다 |

## 4. 이어서 진행할 때 주의 사항
- **배포**: `dist/model-workshop.html`을 그대로 올리지 말 것(예전 링크가 갱신된다). 이 세션은 위 사본 경로·링크로만 올린다. 올리기 전에 `action: read`로 현재 버전을 확인한다.
- **화면 덧붙임 구조**: 모델 탭은 editor가 다시 그릴 때마다 원래대로 돌아오고, `patchPanel()`이 다시 고친다. 새 화면 수정도 `patchPanel()`에 넣고, 한 번 더 돌아도 같은 결과가 나오게(멱등) 만들 것. 동결 파일의 마크업 문구(예: '드림 상태', '그림체', `#mname`)를 찾아 붙이므로 그 문구가 바뀌면 깨진다.
- **대리 조작부**: '3D 표시'는 무대 표시줄의 숨긴 원래 조작부(`#shadesw` 버튼, `#w3o`·`#w3b`)를 대신 누르고 `input` 이벤트를 보낸다. 원래 조작부를 지우면 안 된다.
- **드림 옵션 함수**: `dstep()`(단), `dgap()`(단차), `dov()`(층 겹침, 기준 3), `dshape()`=1, `ddir()`=2 고정. 메쉬 캐시 키에 모두 들어가 있다. 새 옵션을 만들면 캐시 키에도 넣을 것.
- **뼈 등록 순서**: 투구에 `tube`·`ellip`을 더할 때 'mesh'·'bone' 두 모드에서 똑같이 호출할 것(조건은 두 모드에서 같은 값이어야 함). `loft`는 뼈를 등록하지 않는다.
- **한 줄 코드 속 `//` 주석 금지**(`/* */` 사용). world3d2.js는 한 줄에 코드가 많다.
- **카메라 회전**: editor.js가 `VIEW.sq`를 .2~1로 묶는 뒤에 `orbitUI`가 덮어쓴다. `VIEW.uk`는 고정(.93)이라 진짜 회전이 아닌 근사 투영이다.
- **장식 그림판**: 처음 굽는 데 약 200ms(소프트웨어 렌더). 능선 텍스처는 반지름 범위(14)를 넘으면 REPEAT로 감겨 엉뚱한 값을 읽는다. 사슬 두건 뒤쪽 이음선(방위각 ±π)에 가는 선이 보일 수 있다.
- **2D 월드 시험**: 소프트웨어 렌더에서 매우 느리다(한 장에 1분 이상). 한 번 접속에 한 장만 찍는다.
