# 캐릭터툴 작업 진행

대상: 검술대전 모델 공방의 **3D 월드2** (`src/world3d2.js`). 전역 규칙은 `CLAUDE.md`, 작업 내용은 이 문서에 적는다.

## 2026-11-14

### 1. 장식을 셰이더 수식에서 텍스처 읽기로 전환
- 대상: 통·몸통·구 장식(갑옷줄·리벳·테두리·띠·버클·멜빵·가슴 능선), 사슬 무늬, 정강이·아래팔 능선.
- 방식
  - 장식표 줄(`DEC`)을 `atBake()`가 그림판(`AT`, 텍스처 유닛 7)에 미리 굽고, 셰이더는 읽기만 한다.
  - 그림판은 가로 8칸(칸 = 256²). 통·구는 한 칸, 몸통은 2×2칸(앞·뒤).
  - 윗절반 = 바탕색(알파 곱한 RGB, A), 아랫절반 = (R 먹선, G 가슴 능선).
  - `decUp()`은 줄 내용이 같으면 다시 굽거나 올리지 않는다. 줄 내용이 같은 타일은 `AT_TILES`에서 다시 쓴다.
  - 사슬 무늬는 `LT`의 B칸, 정강이·아래팔 능선은 `LT`의 A칸에 구웠다(능선 세로축 = 반지름 0~14).
- 꼬리표: `HLA w = 10 + 종류 + 3·칸 번호`(종류 0 통, 1 몸통, 2 구). 통의 `vh.z`는 (축 위치 + 1) ÷ (길이 + 2), 몸통은 `vh = (좌우/Yh, 높이 0~1, 앞뒤)`.
- 확인: 5개 모델 × 3방향 화면 비교에서 달라진 픽셀 약 200~400개(전체의 0.04% 안팎).
- 알아 둘 점
  - 처음 굽는 데 약 200ms(소프트웨어 렌더 환경). 부품 치수가 바뀌면 그 줄만 다시 굽는다.
  - 사슬 두건 뒤쪽 이음선(방위각 ±π)에 가는 선이 보일 수 있다.
  - 능선 반지름 범위를 6으로 잡았다가 장갑 쪽에 검은 쐐기가 생겨 14로 늘렸다(반지름이 범위를 넘으면 REPEAT로 감겨 엉뚱한 값을 읽는다).

### 2. 금나라 투구 드림 올림을 2D와 비슷하게
- 2D(`knight.js` `jinDraw`)에 있고 3D에 없던 것을 `helm()`의 금나라 투구·투구2 드림 올림 분기에 추가했다.
  - 귀 옆 속드림 자락: 금나라 투구는 양옆 두 자락, 투구2는 옆과 뒤 네 자락. 아래로 갈수록 벌어지고 찰갑 무늬.
  - 밑단 천: 접은 챙 아래 가장자리와 자락 밑단에 천 색 띠.
  - 턱 끈과 매듭: 자락 밑에서 붉은 끈이 나와 턱 앞에서 묶이고 끝자락 두 가닥이 늘어진다.
- 2D는 턱 밑에서 묶지만 3D는 몸통 윗면이 턱 바로 밑이라 끈이 파묻혀서 턱 앞쪽(`HL([6.9,0,-9.4])`)에서 묶는다.
- 끈의 `tube`·`ellip`은 `'mesh'`·`'bone'` 두 모드에서 똑같이 호출한다(뼈 등록 순서 규칙).

- 보완: 드림 올림에서는 귀를 그리지 않는다(`face(true,true)`). 말린 드림(접은 챙)에도 찰갑 무늬를 입혔다(`TAG=1`, `HLOC=null`).

- 보완 2: 드림 올림에서 뒤통수 맨머리에 머리카락을 넣었다(`hairCap()`, 모델의 머리 설정을 따른다). 말린 드림의 위쪽 면이 판판해 보여서 위쪽 면에도 찰갑 무늬를 입혔다. 새 TAG 4 = 찰갑 + 위를 향한 면도 무늬(같은 `LT` 그림을 위에서 내려다본 투영으로 읽는다. 수식으로 그리지 않고 텍스처를 읽는다).

- 되돌림과 수정: 드림 올림 전체 재작성(층층 돔·좁은 자락·늘어진 끈)은 마음에 들지 않아 되돌렸다. 기존 금나라 투구 모양에서 **말린 드림(접은 챙)만** 참고 그림대로 고쳤다. 두 단으로 포개 말린 띠(아래 단은 아래로 벌어지고, 위 단은 한 칸 물러나 계단을 이룸), 윗면·옆면 모두 찰갑 무늬. 사발·속드림 자락·턱 끈은 그대로다.

### 3. 폴리곤 부위별 집계

### 시험 방법 메모
- Playwright chromium, `--use-gl=angle --use-angle=swiftshader`. 3D 월드2 전환은 `#worldsw button[data-world="3d2"]`.
- 시점은 `VIEW.yaw`(옆 0, 비스듬 .6, 정면 1.5708), 피치는 `VIEW.sq`를 직접 바꾼다.
- 금나라 투구 설정: `Object.assign({},KPRESETS[0].m,{armor:'jin',helm:'kit',hkit:{form:'jin',visor:'up',crest:'plume',colors:{}}})`
- 2D 월드는 소프트웨어 렌더에서 매우 느려 화면 한 장에 1분 넘게 걸린다. 한 번 접속에 한 장만 찍는다.
