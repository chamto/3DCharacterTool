## 1. 완료한 일

### 1-1. 렌더링 구조 (3D 월드2)
- **스키닝 전환**: 겉면을 기본 서기 자세에서 한 번만 만들어 GPU에 올리고, 매 프레임 뼈 행렬만 갱신한다.
  - 부품마다 자기 틀(끝점·방향·길이 등)을 뼈로 등록한다. `bone(F)`가 하고, F = [원점, 축1, 축2, 축3]이다.
  - 뼈 행렬 = 지금 틀 × 기본 틀⁻¹이다. 3×4 행렬을 실수 텍스처(`BT`, 한 줄 = 한 명)로 올린다.
  - 자락(치마·망토·앞자락)은 두 뼈를 섞는다. 공식: `A(p) + w·(B(pb) − A(pb))`.
  - 몸통의 숙임(lean)은 전단 행렬 하나로 처리한다(`torsoF`).
  - 같은 뼈대 함수를 MODE `'mesh'`(겉면 생성) / `'bone'`(뼈만 계산)으로 돌린다.
  - 뼈 수가 다르면 그 모델은 예전 방식(매 프레임 겉면 생성)으로 자동 대체된다.
- **인스턴싱 + 한 번에 그리기**: `ANGLE_instanced_arrays`로 같은 메쉬를 인원수만큼 한 번에 그린다. 부품 번호 → 본 그림 → 경계선 단계를 화면 전체에 한 번씩만 거친다.
- **인원 시험 기능**: 무대 좌상단에서 인원 1/50/100/200/300을 고르고 CPU 시간과 fps를 표시한다. 인원은 열 때마다 1로 돌아간다.
- **측정값** (이 작업 환경 기준): 1명 CPU 약 0.3~0.6ms(예전 약 10ms 이상), 200명 CPU 약 12ms. GPU는 실기기 확인이 필요하다.

### 1-2. 명암·선
- **명암 3방식**(무대 좌상단 버튼):
  - 1 툰 조명
  - 2 화면 기준(2D 규칙: 오른쪽 40% 그늘, 왼쪽 16% 광택 띠, 기본값)
  - 3 매트캡
- 판금 그늘색·밝은색은 팔레트 값을 쓴다. 나머지는 바탕색에 먹/흰색을 섞어 만든다.
- **표면 무늬 제거**(사용자 요청): 판금 붓 결, 빗금, 미늘 무늬를 뺐다.
  - 붓터치 그림체(`m.paint==='brush'`)일 때만 붓 결과 붓선(끊기고 흔들리는 선)을 쓴다.
- **외곽선·경계선**:
  - 부풀린 외곽선 패스를 없앴다. 부품 번호 그림(ID 버퍼)에서 배경↔몸(외곽선)과 부품↔부품(경계선)을 따로 검출한다.
  - 8방향 × 2겹으로 비교해 선명하고 매끄럽게 그린다.
- **슬라이더**: 외곽선(px), 경계선(px), 갑옷줄(배)
  - '머리' 슬라이더와 '찰갑선' 슬라이더는 만들었다가 사용자 요청으로 제거했다.

### 1-3. 갑옷·얼굴 표현
- **갑옷줄**(2D와 같은 위치·개수):
  - 겹판 줄, 리벳, 능선, 어깨판 테두리, 목둘레 trim, 등 멜빵, 허리 버클, 허리 겹판 먹선
  - 판과 같은 부품 번호라서 경계선이 생기지 않는다.
- **능선**: 폴리곤을 쓰지 않는다.
  - 정강이·아래팔 능선은 통 둘레 각도를 꼭짓점(HLA w=4)에 적어 셰이더가 긋는다.
  - 가슴 능선은 몸통 셰이더가 긋는다(w=5).
- **찰갑**(금나라 갑옷·투구 드림):
  - 찰갑선 1.5배 기준으로 256² 텍스처(`LT`)에 한 번 구워 둔다.
  - 기본자세 위치에 옆면·앞면 투영으로 입힌다. 선은 먹색이다.
  - 투구 그림이 칠해진 곳(드림 눈구멍)에는 무늬를 넣지 않는다.
- **사슬 무늬**: 사슬 두건과 조립 투구의 사슬 목가리개(HLA w=2, 셰이더 반달 고리).
- **투구 상세 그림**(`helmTex`, 1024×512): 눈 틈, 숨구멍, 리벳 줄, 능선, 금나라 눈썹판·띠.
  - 숨구멍과 눈 틈은 고정 크기다.
  - 나머지는 갑옷줄 배율을 따른다.
- **얼굴 그림**(`faceTex`, 2048×1024, HLA w=3, 머리 국소 원통 좌표): 눈썹, 입, 코 선, X 눈, 가는 눈, 안대(판+끈), 콧수염, 턱수염, 덥수룩한 수염 윗단.
  - 입체로 남긴 것: 머리통, 귀, 눈동자, 코 볼록면, 덥수룩한 수염 덩어리.
  - 얼굴·수염은 어느 슬라이더에도 영향받지 않는다(경계선 제외 처리).
- **귀 추가**: 경계선과 무관하다. 먹 테두리는 뒤에 댄 판으로 만든다. 투구·두건 속에서는 생략한다.
- **눈 옵션**: 점 / 가는 / 부릅뜬 / X 눈. **안대**는 별도 옵션(`m.patch`)이다.
- **두건**:
  - 사슬 두건·천 두건 모두 얼굴 창을 실제로 뚫고, 안의 진짜 얼굴을 보여 준다.
  - 사슬 두건에는 사슬 무늬를 넣었다.
- **면갑 올림 수정**(면갑 투구·뾰족 투구): 얼굴 창을 뚫고, 이마 위로 젖힌 면갑판을 붙인다.
- **금나라 투구 드림 내림**: 눈구멍을 실제로 뚫어서 얼굴 설정(눈·눈썹·안대)이 그대로 반영된다.
- **통투구 위치 버그 수정**: 머리 좌표 변환이 빠져 있던 것을 고쳤다.

### 코드 함정
- **한 줄 코드 속 `//` 주석 금지.** `world3d2.js`는 한 줄에 많은 코드가 있어서, `//`가 뒤 코드를 통째로 주석 처리한다. 이 실수로 스키닝이 꺼지고 팔꿈치 덧판이 빠졌던 적이 있다.
  - 줄 중간에는 반드시 `/* */`를 쓴다.
  - 수정 후에는 `//` 뒤에 코드가 남았는지 점검하는 스크립트를 돌린다.
- **뼈 등록 순서가 'mesh'·'bone' 두 모드에서 같아야 한다.**
  - 지켜야 할 것:
    - `tube`·`ellip`·`boxF`는 두 모드 모두 `bone()`을 호출한다.
    - 겉면 전용 계산(`loft` 인자 계산 등)만 `if(MODE==='mesh')`로 감싼다.
    - 조건부 부품 안의 `tube`/`ellip`을 mesh 전용 블록에 넣지 않는다.
  - 어기면 "뼈 수 불일치" 경고가 뜨고 예전 방식으로 떨어진다.
- **HLA(vec4) w 꼬리표**: 1=투구 상세 그림, 2=사슬 무늬, 3=얼굴 그림, 4=통 능선, 5=가슴 능선. `HLOC.fn`으로 꼭짓점별 값을 넣을 수 있다.
- **TAG**(색 r에 2·TAG를 더해 담음): 0=무늬 없음(피부·망토), 1=찰갑, 2=판금, 3=먹선(명암 없음).
- **텍스처 유닛**:

  | 유닛 | 이름 | 용도 |
  |---|---|---|
  | 0 | ID FBO | 부품 번호 그림 |
  | 1 | `HT` | 투구 상세 |
  | 2 | `ST` | 붓 결(붓터치용) |
  | 3 | `MC` | 매트캡 |
  | 4 | `BT` | 뼈 |
  | 5 | `LT` | 찰갑 |
  | 6 | `FT` | 얼굴 |

  - 0번에 ID 텍스처가 묶인 채로 샘플러 기본값 0을 쓰면 피드백 루프 오류가 난다. `noSkin()`에서 `BT`를 4로 고정해 둔 이유다.
- **변수 이름 충돌**: `ftex`는 ID FBO 텍스처 이름이다. 얼굴 텍스처는 `facetx`다.
- **메쉬 캐시 키**: `JSON.stringify(m)` + 갑옷줄 배율. 모델이나 배율이 바뀌면 겉면을 다시 만든다. 셰이더 값(명암 방식, 외곽선·경계선)은 다시 만들 필요가 없다.
- **군중 표시**: 인원이 2명 이상이면 화면 축소(`s3`, `Y3`)를 쓰고, 고리 드래그는 끈다.
- **현재 폴리곤 분포**: 판금 기사 약 1만 600개 중 통(팔다리)과 타원체가 대부분이다. 추가로 줄이려면 LOD가 다음 단계다.
