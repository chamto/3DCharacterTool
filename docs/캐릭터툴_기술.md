# 캐릭터툴 기술 사항

## 2D 섬광 검기

재생 패널 "검 궤적 효과"에서 `섬광 검기`(또는 `둘 다`)를 고르면 2D 월드에서 타격 키 동안 칼이 지나간 자리를 밝은 빛 판으로 보여 준다. 코드는 동결된 2D 파일에 있다(`src/core.js` 183~247줄, 호출은 `src/editor.js` 150~156줄). 3D 월드2의 섬광 궤적(`src/world3d2.js` 704줄~)은 이 규칙(빛줄기 방향 등)을 따라 3D 띠로 다시 만든 것이다.

### 1. 전체 구조: 미리 만든 빌보드를 칼이 지나간 만큼 드러내기
- 매 프레임 칼 자취를 쌓아 그리지 않는다. **타격 키에 들어가는 순간 궤적 전체를 감싸는 빌보드(빛 판) 한 장을 미리 만들고**, 지금 칼선 뒤(시작 칼 쪽)만 남겨 보여 준다. 체력 막대가 차오르듯 칼을 따라 드러난다.
- 그래서 재생 배속·프레임 속도와 상관없이 같은 모양이 나온다.

### 2. 칼 위치 미리 따라가기 (`editor.js` 153~154줄)
- 타격 키 판정: `isStrikeKey(k)` = `k.lunge>0` 이거나 키 이름에 `타격|찌름|찌르기|베기|막기`가 들어 있음.
- 새 타격 키에 들어오면(`PB.swIdx!==PB.idx`) 앞 키 자세 → 타격 키 자세를 `mixK(P0(pk.pose),k_.pose,t)`로 15단계(t=0~1, q=0..14) 보간한다.
- 각 단계마다 보이지 않는 캔버스(`FXDUMMY`)에 `drawModel`을 원점 기준(X=0,Y=0)으로 그려 손(`h`)·칼끝(`a`) 위치만 얻는다. 이때 `RENDER_LQ=true`(저품질)로, `HINTS`·`seed`는 저장했다가 되돌려 실제 그림에 영향이 없게 한다.
- 결과 배열 `SM=[{h,a}...]`로 `buildSweep(SM)`을 호출해 `PB.sw`에 둔다. 타격 키가 아니면 `PB.sw=null`.
- 매 프레임 실제 칼 위치를 원점 기준으로 바꿔 `PB.sw.cur={h,a}`에 넣는다.

### 3. 빌보드 모양 만들기 (`buildSweep`)
A = 시작 칼(SM 첫 칸), B = 끝 칼(SM 마지막 칸). 좌표는 모두 모델 원점 기준 2D.

| 요소 | 정의 |
|---|---|
| 바닥 | B 칼날(손 hB → 칼끝 tB). `bd` = 바닥 방향 |
| `w` | 바닥에 수직, 궤적(A) 쪽을 향함. SM 점들의 부호 합으로 방향을 정한다 |
| 경계 1 (`d1`) | A 손 → B 손 방향. 두 손이 6px 안으로 가깝거나 `w`와 거의 수직이면 `w`로 세운다 |
| 경계 2 (`d2`) | B 칼끝 → 궤적의 "최고 높이점" T. T는 바닥에서 가장 바깥으로 솟은 칼끝(B 칼끝 근처 15% 이내 점은 건너뜀). 이 선 안에 궤적이 모두 든다 |
| 윗변 높이 `D` | SM의 손·칼끝 중 바닥에서 가장 먼 거리 × 1.08 |
| P1, P2 | 경계 1·2가 높이 D에 닿는 점 |

- 사각형 안 좌표 함수 `at(t,v)`: t는 바닥을 따라(0=손, 1=칼끝), v는 높이(0=바닥, 1=윗변). 왼변 hB→P1, 오른변 tB→P2를 v로 보간한 뒤 그 사이를 t로 보간.

#### 섬광 꼬리(손가락 모양 빛꼬리)
- 판의 윗부분은 곧은 윗변이 아니라 **손가락처럼 갈라져 끝이 둥근 빛줄기 다발**이다. 가운데 손가락이 가장 길다.
- 안내선 `TV(t) = TPOS + TARC·sin(πt)`: 꼬리가 갈라지기 시작하는 호. `TPOS`=꼬리 안내선 위치(`fxTailPos`, 0이면 B 칼날에서 바로), `TARC`=꼬리 호 높이(`fxTailArc`).
- 손가락 수 `NF` = `fxTailN`(1~30). k번째 손가락은 칸 [k/NF,(k+1)/NF], 반폭 `hw`=칸 반폭×0.84.
  - 길이 `ln` = 양 뿌리·가운데 중 높은 안내선 높이 + `L0·(0.6+0.4·sin(π·tm))` + 작은 흔들림(`0.03·sin(2.3k+1)`). `L0 = max(0.25, 1.2−TPOS)`.
  - 끝은 반지름 `tr=min(0.12, hw·1.5)`의 반원(10분할)으로 둥글게.
  - 이웃 손가락은 안내선 위의 같은 뿌리 점을 함께 써서 사이가 V자 고개가 된다.
- 최종 다각형 `poly = [hB, tB, ...꼬리점들]`.

#### 빌보드 이미지 굽기
- poly를 감싸는 사각형(+4px 여백)에 2배 해상도 캔버스를 **두 장**(흰빛 fl=1, 옅은 노랑 fl=0) 만든다. 색 `FX_COL`: 흰 `[255,255,255]`, 노랑 `[255,244,170]`.
- 바탕: 바닥 가운데에서 `w` 방향으로 선형 그라데이션(불투명도 1 → 0.85 → 0.45).
- **빛줄기**(섬광 방향 줄기): poly로 오린 안에 `NS = round(30·fxDen)`개. 같은 비율 t의 위쪽 점 `at(t,v1)` → 아래쪽 점 `at(t,v0)` 방향(즉 꼬리에서 바닥 B 칼날 쪽으로 흐름). v0 = 0.12~0.62, v1 = v0+0.25~0.75. 세 개 중 하나는 굵은 흰 줄기(2.2~5.2px), 나머지는 가는 색 줄기(0.9~2.3px, 흰 차례엔 파랑 `rgba(90,135,210)`, 노랑 차례엔 주황 `rgba(200,130,20)`). 각 줄기는 시작이 투명하고 70% 지점에서 가장 진하다. 난수는 `sin` 해시(`rn(k,q)`)라 매번 같다.
- 반환: `{imgs, x0,y0,w,h, A,B, cur:A, d1,d2, poly}`.

### 4. 합친 외곽선 (`sweepOutline`)
매 순간 그릴 도형 = **[빌보드 판에서 지금 칼선 뒤(A 쪽)만 남긴 부분] + [칼날 앞 섬광 머리]** 를 테두리 하나로 이은 것.
- 판 자르기: 지금 칼선(손 h → 칼끝 a)과 법선 `n`(A 쪽)으로 Sutherland–Hodgman 반평면 자르기. 잘린 변의 두 끝(`cut`)을 기억한다.
- 섬광 머리: 칼날 앞쪽(−n 방향)으로 볼록하게 내민 3차 베지어 두 개(각 12분할). 손 h → 가운데 M(칼날 중점에서 −n으로 `K·1.2`) → 칼끝 a. 제어점은 d1·d2 방향과 칼선 방향(`dl·0.28`)을 쓴다. `K = 칼 길이·0.07·1.35`.
- 잘린 변(칼선 위) 자리에 섬광 머리를 끼워 넣는다. 잘린 변이 다각형 중간이면 그 사이에, 닫는 변이면 끝에 붙인다. 칼선 방향 좌표(`along`)로 머리를 뒤집을지 정한다.
- 칼선이 판을 자르지 못하면(cut<2) 남은 판 + 머리, 또는 머리만.
- 주의: 빌보드 모양을 바꾸면 이 합치기도 함께 맞춰야 한다.

### 5. 그리기 (`drawSweep`)
- 반짝임: `fl = floor(clock/fxPer)%2`. `fxPer`(반짝임 주기, 30~300ms)마다 흰빛·노랑을 번갈아 쓴다. 노랑 차례에는 B 손을 중심으로 전체를 1.06배 키워 울렁이게 한다.
- 순서:
  1. 섬광 머리 빛무리: `K·fxGlow`로 다시 만든 머리를 불투명도 0.35로 칠함(`fxGlow`>1일 때).
  2. 합친 도형으로 오리고, 머리를 단색으로 칠한 뒤 빌보드 이미지(`imgs[fl]`)를 얹는다.
  3. 테두리선을 합친 도형에 한 번만 긋는다(1.6px, 흰 차례 파랑 `rgba(100,140,205,.6)`, 노랑 차례 `rgba(200,140,30,.65)`).
- 사라짐: `S.end`가 있으면 끝난 뒤 200ms 유지, 220ms 동안 옅어짐. 지금 편집기는 `S.end`를 넣지 않고 타격 키가 끝나면 `PB.sw=null`로 바로 지운다.

### 6. 그리는 층 (`editor.js` 150~155줄)
1. 인물보다 **먼저** `drawSweep`로 빌보드 전체를 그린다(인물 뒤).
2. 인물(`drawModel`)을 그린다.
3. `drawBladeGlow`: 칼날 번쩍임.
4. 인물 **위에** `drawSweep(..., blade=[r.b, r.a])`를 한 번 더: 빌보드 판은 칼날 둘레 좁은 띠(칼날 양옆 7px, 칼끝 너머 4px) 안에서만 보이고 섬광 머리는 그대로. 빛이 칼을 감싸 보이되 몸은 덮지 않는다. 테두리선은 머리에만 긋는다.

### 7. 칼날 번쩍임 (`drawBladeGlow`)
- 최근 140ms 자취(`pushTrail`로 쌓은 `PB.trail`, 수명 170ms)에서 칼끝이 14px 넘게 움직였으면 `glowT`를 지금으로 갱신.
- `glowT`로부터 260ms 동안 칼날(r.b→r.a)에 세 겹 선(굵기 16·9·4.5px, 불투명도 0.25·0.5·0.95)을 흰빛·노랑 번갈아 긋고, 1px 테두리선. 120ms 뒤부터 140ms 동안 옅어진다.

### 8. 옵션 (`opt`, `model-ed-opt`에 저장)

| 키 | 화면 이름 | 범위(기본) | 쓰이는 곳 |
|---|---|---|---|
| `trailFx` | 검 궤적 효과 | ink/flash/both/none (ink) | flash·both일 때 섬광 검기 |
| `fxDen` | 섬광 빛줄기 | 0~3 (1) | 빛줄기 수 = 30×값 |
| `fxTailN` | 꼬리 갈래 수 | 1~30 (5) | 손가락 수 |
| `fxTailPos` | 꼬리 안내선 위치 | 0~0.85 (0) | 꼬리 시작 높이 |
| `fxTailArc` | 꼬리 호 높이 | 0~1 (0.5) | 안내선 호의 볼록함 |
| `fxGlow` | 섬광 머리 빛무리 | 1~2.5 (1.2배) | 머리 바깥 빛무리 배율 |
| `fxPer` | 반짝임 주기 | 30~300ms (60) | 흰빛·노랑 교대 주기 |

- 옵션은 `fxO(k,d)`로 읽는다(`opt`가 없으면 기본값). 꼬리 옵션은 빌보드를 만들 때(타격 키 시작) 반영된다.

### 9. 참고: 먹 궤적과의 차이
- `먹 궤적`(`drawTrail`)은 미리 그려 둔 먹 호 이미지(`SLASH_IMG`: 휘두른 각도 40~180°×안쪽 비율 4종)에서 가장 가까운 장을 골라 손을 축으로 돌려 붙이는 방식이고, 최근 170ms 자취만 쓴다. 섬광 검기는 자취가 아니라 앞 키→타격 키 보간으로 궤적 전체를 미리 계산한다.

## 3D 섬광 검기 (3D 월드, `src/world3d2.js`)

2D 섬광 검기와 같은 계산을 3D에 옮겼다(2026-11-17). 예전 3D 섬광은 칼날 자리를 이은 반투명 띠 + 가는 빛줄기 + 삼각형 꼬리라서 판이 성기고 섬광 머리·테두리가 없었다. 먹 궤적도 2D 방식으로 바꿨다(아래 "3D 먹 궤적"). 예전 띠 함수 `fxDraw`는 없앴다.

- **휘두르는 면 평면(`fxPlane`)**: 타격 시작 때 미리 구한 칼날들(`SM`, 코등이 g → 칼끝 t, 17단계)에서 평면을 잡는다. 중심 C = 칼날 중점들의 평균, 법선 N = 이웃 칼날 사이의 (칼날 방향 × 칼끝·코등이 움직임) 합(부호를 맞춰 더함). 움직임이 거의 없으면 끝 칼날 × 위쪽. e1 = 끝 칼날 방향을 평면에 투영, e2 = N × e1.
  - 평면 좌표 = (p−C)·e1, (p−C)·e2에 `FXK`(1.4)를 곱한 값. 2D 화면 픽셀과 비슷한 크기라 2D의 선 굵기(빛줄기·테두리·번쩍임)를 그대로 쓴다.
- **빌보드 만들기(`fx2Build`)**: 2D `buildSweep`과 같은 식(바닥 = 끝 칼날, 경계 1·2, 윗변 D, 손가락 꼬리, 빛줄기 두 장). 다른 점: 여백(칼날 길이×0.3+8)을 두어 섬광 머리·빛무리·6% 확대가 캔버스 밖으로 나가지 않게 하고, 캔버스 배율 `RS`는 최대 2배·한 변 1024 이하.
- **매 프레임(`fx2Paint`)**: 지금 칼날을 평면 좌표로 바꿔 2D `sweepOutline`과 같은 식(`fx2Out`)으로 판을 칼선에서 자르고 섬광 머리를 끼운다. 빛무리 → 합친 도형 안 칠하기 → 테두리선 → 칼날 번쩍임(세 겹)을 캔버스 한 장(`fxcv`)에 그린다. 2D처럼 인물 앞뒤로 두 번 그리지 않고, 깊이 비교로 몸 뒤는 가려진다.
- **올리기·그리기(`fxRun`)**: 캔버스를 텍스처(`fxtex`)로 올려 평면 위 사각형 하나(삼각형 2개)에 붙인다. 텍스처 유닛이 0~7 모두 쓰여 있어 그리는 동안만 2번(`ST`) 자리에 `fxtex`를 묶고 끝나면 `stex`로 되돌린다. 셰이더 `flat_`=5: `texture2D(ST, vn.xy)`(꼭짓점 법선 자리에 (u, v, 1)을 넣음. z를 1로 두는 것은 `normalize(N)`이 0벡터가 되지 않게 하려는 것).
- 두 렌더 경로(스키닝·예전 방식)가 모두 `fxRun` 하나를 부른다. 섬광·먹 궤적 모두 평면 캔버스 → 텍스처 → 사각형(`fxQuad`) 순서로 그린다.
- **한계**: 평면이라 휘두르는 면을 옆으로 보면(예: 위에서 내려베기를 정면에서) 얇은 선으로 보인다. 2D에서도 이때는 칼 자리가 화면에서 한 줄로 겹쳐 판이 얇다.

## 3D 먹 궤적 (3D 월드, `src/world3d2.js`)

2D 먹 궤적(`drawTrail`)의 모양(먹색 초승달 + 종이색 결 세 줄)을 실제 칼 자취를 따라가는 3D 띠로 그린다(2026-11-17).
- 처음에는 2D처럼 미리 그린 호 그림을 평면에 돌려 붙였으나, 각도가 5단계로 반올림되고 평면 투영이 섞여 먹이 칼에서 떨어졌다(가위 공격에서 두드러짐). 그래서 띠 방식으로 바꿨다.
- **자취(`FX.tr`)**: 타격 첫 프레임부터 재생이 끝나거나 처음 키 쪽으로 돌아갈 때까지(타격 뒤 제자리로 돌아가는 동작 포함) 칼의 이동 전체를 모은다. 손(`K.hd`)·코등이·칼끝(3D)을 칼끝이 0.3 넘게 움직였을 때만 넣는다. 첫 칸은 시작 칼(앞 키 자세, `FX.SM[0]`). 시간으로 버리지 않는다.
- **그리는 범위 옵션**(`opt.inkRange`, `model-ed-opt`에 저장): `all` 칼 이동 전체(기본) / `strike` 타격만(타격 키 동안만 자취를 모음, 남기는 것은 같음). 동작 탭에서 검 궤적 효과가 '먹 궤적'이고 3D 월드일 때 '먹 궤적 그리는 범위(3D 월드)' 버튼 줄(`#w3inkr`)이 검 궤적 효과 버튼 아래에 붙는다(`patchPanel`이 넣음, 편집기 코드는 그대로). 읽기는 `inkRange()`.
- **획 나누기**: 이웃 칸마다 손 둘레 회전축(칼 방향 외적)을 첫 큰 회전축(REF)과 비교해, 도는 방향이 바뀌면(내려치고 되돌아감) 새 획으로 나눈다. 0.02rad 미만의 작은 회전은 지금 획에 붙인다. 획마다 아래 식으로 초승달 띠를 따로 만든다(각 획의 끝 = 그 획의 마지막 칼이 가장 두꺼움). 휘두른 각도가 0.3rad 미만인 획은 그리지 않는다.
- **띠 만들기(`fxInk`, 획마다)**: 이웃 칸 사이를 손 둘레 각도 0.06rad 간격으로 잘게 나눈다(손 위치 보간, 칼 방향 정규화 보간, 길이 보간). u = 칼끝이 지나온 길이 비율(0 시작 → 1 지금 칼).
  - 바깥 가장자리 = 손 + 방향 × 길이 × (1 − 0.03(1−u)), 안쪽 가장자리 = 손 + 방향 × 길이 × (1 − (1−rin)·u^1.5). 2D `makeSlash`의 outr·inr과 같은 식이라 지금 칼 쪽이 가장 두껍고 시작 쪽은 가늘다. 바깥 끝이 지금 칼날 자리라 먹이 칼에 붙는다.
  - rin = 코등이/칼끝 거리 비율(0.1~0.78로 제한). 불투명도 min(1, 획의 각도/0.9).
- **무늬 텍스처(`fxInkTex`)**: 띠 좌표(u 가로, v 세로: 바깥 0 → 안쪽 1) 512×128 캔버스에 먹색 바탕 + 종이색 결 세 줄(2D와 같은 f0·굵기·u 범위, 굵기는 그 자리 띠 폭으로 나눠 v 단위로). rin이 바뀔 때만 다시 굽는다. 그리는 동안 2번 유닛(`ST`)에 묶는다. 셰이더 `flat_`=5에서 색 자리 r(=불투명도)을 텍스처 알파에 곱한다(0이면 1).
- **깊이**: 2D처럼 칼·몸 뒤에 보이도록 먹 띠는 `polygonOffset(2,8)`로 살짝 뒤로 민다(섬광은 −2로 앞으로).
- **남기기(`fxKeep`)**: 타격 키가 끝나도 재생 중이고 지금 키 번호가 타격 키 번호 이상이면 계속 자취를 모으고 그린다(새 칸이 없으면 `FX.ev`를 다시 씀). 재생이 멈추거나 반복 재생으로 처음 키 쪽으로 돌아가면 지운다. 재생 상태는 `W3HOST.PB`로 읽는다.
- 쌍칼(두 번째 칼) 자취는 3D에 없다.
