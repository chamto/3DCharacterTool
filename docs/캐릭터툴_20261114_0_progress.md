### 1-3. 갑옷줄 → 장식표(AT) + 셰이더
폴리곤이던 아래 항목을 부품별 장식표 줄과 셰이더로 바꿨다.
- **통(팔다리)**: 겹판 줄, 리벳, 테두리 띠(rim)
- **몸통**: 허리 겹판 먹선, 목둘레 trim, 등 멜빵, 허리띠, 앞 버클, 가슴 능선
- **구**: 팔꿈치 덧판 둘레의 리벳 점. 무릎 리벳은 통 리벳으로 처리
- 제거한 폴리곤: 팔꿈치·무릎 먹 타원체, 띠·버클·멜빵·trim 겉면 등
- **결과**: 판금 기사 4종 폴리곤 약 1만 800~1만 1천 5백 → **약 8천 4백~9천 1백**
- 화면 비교(전/후), 갑옷 종류(금나라 갑옷 포함)·붓터치 그림체·군중 50명으로 확인했다. 콘솔 오류는 없었다.

### 코드 함정
- **줄 중간에 `//` 주석 금지.** 뒤 코드가 통째로 주석이 된다. `/* */`를 쓴다.
- **뼈 등록 순서가 `'mesh'`·`'bone'` 두 모드에서 같아야 한다.** `tube`·`ellip`·`boxF`는 두 모드 모두 `bone()`을 호출하고, 겉면 전용 계산만 `if(MODE==='mesh')`로 감싼다. 어기면 "뼈 수 불일치"로 예전 방식으로 떨어진다.
- **HLA(vec4) w 태그**: 1 투구 상세, 2 사슬, 3 얼굴, 4 통 능선, **10 이상 = 장식표 줄 번호(10+줄)**.
- **장식표(AT)**: RGBA32F, 줄당 8칸, 텍스처 유닛 7. `decRow()`로 줄 추가, `decUp()`으로 올린다. 종류 0 통, 1 몸통, 2 구.
  - 장식을 쓰는 부품은 `tube()`·몸통·`ellip` 앞에서 `HLOC={fn:...}`로 꼭짓점별 좌표를 넣는다. `DEC=[]`는 `HLA=[];SKA=[];MODE='mesh'` 자리에서 초기화한다.
  - 이미 `HLOC`가 있는 부품(투구·사슬·얼굴 등)에는 장식을 중복해서 붙이지 않는다(`!HLOC` 조건).
- **TAG**(색 r에 2·TAG): 0 무늬 없음, 1 찰갑, 2 판금, 3 먹선(명암 없음).
- **텍스처 유닛**: 0 ID FBO, 1 HT, 2 ST, 3 MC, 4 BT, 5 LT, 6 FT, 7 AT. 0번에 ID 텍스처가 묶인 채 샘플러 기본값 0을 쓰면 피드백 루프 오류가 난다.
- 변수 이름: `ftex` = ID FBO 텍스처, `facetx` = 얼굴 텍스처.
- 메쉬 캐시 키: `JSON.stringify(m)` + 갑옷줄 배율. 장식표 줄도 이때 다시 만들어진다.
- 얼굴 텍스처 좌표: 머리 국소 원통 좌표 `(.5+atan2(y,x+1)/2π)*FW, (20-z)/34*FH`.

### 시험 방법
- 스크린샷: Playwright chromium, `--use-gl=angle --use-angle=swiftshader`. 3D 월드2 전환은 `#worldsw button[data-world="3d2"]`.
- 시험 모델 설정: `proj.model=Object.assign({},KPRESETS[i].m,{fEye:'dot',hair:'short'});proj.keys=[mkKey('자세',KP.mid)];proj.sel=0;renderAll();wake(3000)`
- 삼각형 수: `R3D2.stat().verts/3`
- 군중 50명 화면은 소프트웨어 렌더에서 시간 초과가 나서 콘솔 오류 여부와 CPU 시간으로만 확인했다.
- 시험용 스크립트는 세션 임시 폴더에 있어 사라질 수 있다. 필요하면 다시 작성한다.
