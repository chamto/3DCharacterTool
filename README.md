## 3D 월드2: 폴리곤 → 텍스처/셰이더 전환 기록
- **눈동자**: 입체 공 대신 얼굴 그림(`faceTex`)에 먹색 원으로 그린다. 안대 쪽 눈은 그리지 않는다.
- **갑옷줄**: 폴리곤을 없애고 **장식표(AT)** 와 셰이더로 그린다.
  - AT = 실수 텍스처(텍스처 유닛 7). 한 줄 = 장식이 붙는 부품 하나(RGBA 8칸). 꼭짓점 꼬리표 `w = 10 + 줄 번호`.
  - 종류(첫 칸) 0 **통**: 겹판 줄, 리벳, 어깨판 윗단 테두리. 꼭짓점에 (둘레 cos, sin, 축 위치 0~1)을 적는다.
  - 종류 1 **몸통**: 허리 겹판 줄, 목둘레 테두리, 허리띠, 앞 버클, 등 멜빵, 가슴 능선. 꼭짓점에 (좌우, 높이, 중심선 앞뒤)를 적는다.
  - 종류 2 **구**: 팔꿈치 리벳. 리벳 방향을 x축으로 한 좌표를 적는다.
  - 코드: `decRow()`(줄 추가), `decUp()`(업로드), 셰이더의 `dt_()`와 `dcB/dcK/dcR`.
- 예전 HLA 꼬리표 5(가슴 능선)는 몸통 줄로 흡수됐다. 꼬리표 4(통 능선)는 그대로다.
- 바뀐 점: 허리띠·버클·등 멜빵은 겉면에서 튀어나오지 않고 납작하게 칠해진다. 허리띠·버클의 테두리는 부품 경계선이 아니라 고정 굵기(0.4) 먹선이다.
